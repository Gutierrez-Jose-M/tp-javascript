# TP2 - Programador Junior: Interactividad con JavaScript
## Descripción del Proyecto
Este proyecto consiste en una aplicación web interactiva dividida en tres secciones principales, desarrollada para practicar la manipulación del DOM, el manejo de eventos y el consumo de APIs externas.

## Secciones
Productos: Un catálogo con sistema de filtrado dinámico por nombre, categoría, stock y rango de precio.
Lista de Tareas (To-Do App): Una herramienta para gestionar actividades diarias, permitiendo agregar, completar y eliminar tareas con un contador en tiempo real.
Buscador Pokémon (API): Interfaz que conecta con PokéAPI para buscar y visualizar tarjetas de Pokémon de forma dinámica.

## Tecnoligias usadas
HTML5: Estructura semántica de las páginas.
CSS3: Diseño responsive con Grid y Flexbox, variable y efectos visuales.
JavaScript ES6+: Lógica de programación, manipulación del DOM y métodos de arrays.
Fetch API: Consumo de datos desde PokéAPI.
